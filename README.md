Projeto final em equipe da disciplina de **Desenvolvimento Web com React** da residência em software do **Serratec (2021)**.

Front-end de uma loja virtual com **cadastro de usuário** e **listagem de produtos**, organizado em componentes reutilizáveis (Navbar, Logo, formulários).

## Destaques técnicos

- Componentização e rotas com **React Router**
- Estilização com **styled-components** e CSS
- Integração com a API via **Axios**
- Trabalho em equipe com Git (branches `main` e `develop`)

## Como executar

```bash
yarn install
yarn start
```

> A API de back-end era disponibilizada pela disciplina e rodava localmente em `http://localhost:8000`.
